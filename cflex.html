What is flexbox?

Flexbox is short for Flexible Box Container Layout. It is a webpage layouting method that makes use of flex containers and flex items within those containers.

Syntax: 
<div style="background-color: white; padding: 5px;">
  Flex Container
  <div style="display: flex; background-color: white;">
    <div style="background-color: rgb(75, 175, 228); margin: 10px; padding: 2px">Flex Item 1</div>
    <div style="background-color: rgb(75, 175, 228);; margin: 10px; padding: 2px">Flex Item 2</div>
    <div style="background-color: rgb(75, 175, 228);; margin: 10px; padding: 2px">Flex Item 3</div>
  </div>
</div>

Flex Container

The flex container is the parent element containing flex items. Adjusting its properties will affect how the flex items are arranged within.

Axes

A flex container has two axes: main axis and cross axis. The orientation of these axes depends on the direction of the flex items, determined by the set flex-direction value.

The main axis goes along the direction of the items.

The cross axis goes perpendicular to the main axis.

Flex direction set to row
Flex direction set to column

Properties

Flexbox Container Properties
Property Syntax Description
Display display: sets how the container behaves with surrounding elements: <flex> for block or <inline-flex> for inline
Flex Direction flex-direction: sets the direction of the flex items
Flex Wrap flex-wrap: determines whether flex items wrap go to the next line when there is insufficient space
Flex Flow flex-flow: shorthand property for flex direction and flex wrap
Justify Content justify-content: sets horizontal alignment (along main axis) of flex items
Align Items align-items: sets vertical alignment (along cross axis) of flex items
Align Content align-content: sets alignment if flex items wrap
Gap gap: sets gap size between items
Row Gap row-gap: sets gap size between row items
Column Gap column-gap: sets gap size between column items

Try manipulating this flexbox model via devtools (F12).

Examples

Syntax: 

  color: white;
  height: 300px;
  text-align: center;
  display: flex;
  flex-direction: row;
  justify-content: flex-end;
  flex-wrap: wrap-reverse;
  align-items: stretch;
  align-content: stretch

Flex Item

The flex item is the child element inside the flex container. Adjusting its properties will also affect how the flex items are arranged within.

Properties

Flexbox Item Properties
Property Syntax Description
Order order: sets the item's order relative to the others
Flex Grow flex-grow: sets how much the item grows relative to the others
Flex Shrink flex-shrink: sets how much the item shrinks relative to the others
Flex Basis flex-basis: sets the item's initial length
Flex flex: shorthand property with values defined in the order following the order of the properties listed above (grow, shrink, basis)
Align Self align-self: sets the item's alignment, overriding the align-item value

Take note that the flex basis value will be added upon when the container is bigger than the total for all items and the flex grow is not greater than 0.

Examples

Try changing the value of each property in the following code using the Developer Tools (DevTools) to see the effects.

  1. Press F12 to open DevTools
  2. Go to Elements
  3. Look for and expand the <style> element
  4. Right-click code and select "Edit as HTML"
  5. Type edits
  6. Press Ctrl + Enter to apply edits
